# Initial App Store screenshot set

Normal Release simulator build **1.0 (8)**, unchanged product source **7c5b955**.
Raw captures came from Simulator's Save Screen control on iPhone16e/iOS26.3.
The saved controlled account restored; no new sign-in credentials were entered.
Create was opened through Host a game; its existing Basketball/RWC Park/default
capacity10/Intermediate selections were not edited. The form was closed and
**Discard** selected, without pressing Create session or publishing a game.

Three raw PNGs are retained unchanged at1170×2532. Static HTML/CSS layouts add
headings and proportional framing; no app controls/data were painted, replaced
or removed. CUA rendered exact1206×2622 clips for the required Dynamic Island
medium-display slot. Exported files are opaque, three-component RGB JPEGs.
All three layouts and raw captures were visually reviewed: no private account
details, participants, message contents, test controls or fabricated game feed.

The set deliberately covers the creation flow. It does not establish physical
game creation, notification delivery, or the complete acceptance matrix.
More discovery/chat assets can be added after approved representative demo data
is available; do not replace screenshots with invented product UI.

`manifest.json` records capture provenance, dimensions and SHA256 hashes.
To render locally, serve this directory on localhost and open each HTML file in
Chrome. Use a1206×2622 clip at CSS coordinates0,0; browser full-page output may
include a wider minimum native window and must not be uploaded without checking.
The screenshot tool returned JPEG bytes, so use `.jpg`, not `.png`, for exports.
