## Proposed notes

PickUp UCF helps the UCF community organize pickup sports. On Welcome, tap
**Sign In** and use the dedicated demo account supplied in Sign-In Information.
Normal new-account registration requires an eligible UCF email address.

The main tabs are **Discover**, **My Games**, **Create**, and **Profile**.
Discover supports list and map views and sport/time/skill filters. Create opens
the game form. Game details contain the roster and session chat. My Games has
upcoming games and expandable past-game history.

Location, Calendar and notification permissions are optional for basic browsing
and sign-in. Add to Calendar creates an independent copy; it does not update
when the host edits or cancels a game. Saved copies can be edited or removed in
Calendar. The widget extension provides session Live Activities, with no separate
Home Screen widget. Push notifications and Live Activities need a physical iPhone.

Profile settings contain support, privacy, community rules, blocked users and
account controls. Session options support reporting and blocking. Please contact
the review contact before deleting the shared demo account so we can provide a
separate disposable account for that check.

There are no purchases, subscriptions, advertising or cross-app tracking.
